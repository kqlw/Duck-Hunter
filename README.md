🎯 Duck Hunter
Классическая аркадная 2D-игра в стиле ретро, вдохновленная культовой Duck Hunt. Управляйте прицелом, отслеживайте появление уток на экране и зарабатывайте очки за каждое точное попадание!

🌟 Особенности
🦆 Динамичный геймплей: Утки появляются в случайных местах и перемещаются по экрану.

🎯 Система прицеливания: Управление с помощью мыши .

💯 Подсчет очков : ведение счета за сбитых уток.

🎨 Ретро-стилистика: Простая пиксельная или спрайтовая графика.

🛠 Технологии и стек
Язык программирования: HTML / CSS / JavaScript
